FreelanceRadar — multi-source monitoring with LLM filtering

running

A web application that polls five job boards through their public APIs and RSS feeds, scores every incoming listing against a profile, and drafts a proposal for the ones worth answering. Over 1,100 listings processed so far. This is the reference build for everything on this page.

  • Connector architecture — adding a sixth source means writing one file, not a rewrite
  • Two-layer scoring: a free rule filter first, an LLM pass only on what survives, so discarded items never cost an API call
  • Kanban tracking, Telegram notifications, dashboard metrics
  • Built ToS-safe on purpose: request throttling, robots.txt checked, honest User-Agent, no headless login, no CAPTCHA solving, no automated submission

Price tracker

running

Checks a set of product pages on a schedule, accumulates prices to CSV, and reports what went up or down since the previous run. The small version of the monitoring service above.

CSV list cleaner

running

Turns a messy contact export into a clean table — the step that usually sits between a scrape and something useful. Importantly, it never invents a value it isn't sure about; those rows go to a separate "needs a human" report.

  • Normalises phone numbers to one format and flags non-mobile entries
